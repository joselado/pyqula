# pyqula user guide

The user guide is a website: <https://joselado.github.io/pyqula/>.

Its pages are the Markdown files in `documentation/guide/`, built with MkDocs
from `mkdocs.yml` in the root of the repository. The whole guide is also
available as one [PDF](https://joselado.github.io/pyqula/user_guide.pdf),
built from the same pages by `documentation/build_guide_pdf.py`.
